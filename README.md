# Cyberpunk Tetris

A classic Tetris game with a cyberpunk aesthetic, built with modern, framework-less web technologies.

[![Deploy to GitHub Pages](https://github.com/Kangn-nova-lab/cyberfunk-type/actions/workflows/deploy.yml/badge.svg)](https://github.com/Kangn-nova-lab/cyberfunk-type/actions/workflows/deploy.yml)

## Features
- **Futuristic UI:** Cyberpunk aesthetics with glowing effects and a retro-futuristic font.
- **Classic Tetris Gameplay:** Move and rotate falling tetrominoes to clear lines.
- **Scoring:** Keep track of your score as you clear lines.
- **Next Piece Preview:** See the next piece that will fall.
- **Leaderboard:** Track high scores, stored locally in the browser.
- **Partnership Inquiry Form:** A modern, integrated form for partnership requests.
- **Disqus Comments:** A comment section for community discussion after the game.
- **Responsive Design:** Works on various screen sizes.

## Deployment
This project is automatically deployed to **GitHub Pages** via a GitHub Actions workflow. Every push to the `main` branch will trigger a new deployment.

## Technologies Used
- HTML5
- CSS3 (Modern Baseline features like variables and flexbox)
- Vanilla JavaScript
