# Cyberfunk Type

[![Deploy to GitHub Pages](https://github.com/Kangn-nova-lab/cyberfunk-type/actions/workflows/deploy.yml/badge.svg)](https://github.com/Kangn-nova-lab/cyberfunk-type/actions/workflows/deploy.yml)

A high-octane, cyborg-themed typing game.

## Features
- **Futuristic UI:** Cyberpunk aesthetics with glowing effects.
- **Dynamic Gameplay:** Falling words that challenge your speed and accuracy.
- **Leaderboard:** Track high scores locally.
- **Responsive Design:** Works on various screen sizes.

## Deployment
This project is automatically deployed to **GitHub Pages** via a GitHub Actions workflow. Every push to the `main` branch will trigger a new deployment.

## Technologies Used
- HTML5 / CSS3 (Modern Baseline features)
- Vanilla JavaScript (ES Modules)
- GitHub Actions for CI/CD
